ExpressTask Submission Status

This is an unfinished Express.js API project.

Implemented:
 User signup with a check for an existing email
 Login by matching the stored email and password
 Listing, adding, updating, and deleting products
 Sample data for users, products, and carts

Not yet implemented:
 Cart operations
 Order creation and management
 Input validation and secure password storage
 Login sessions or tokens

Data is stored in memory and resets when the server restarts. Product ID generation and handling missing fields in product updates still need improvement

To run:
1. Run npm install
2. Run npm run dev
3. The server starts at http://localhost:3000

I am submitting the current version before the deadline and plan to complete the remaining features.
